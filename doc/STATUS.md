# 개발 현황 (STATUS)

> 기준일: 2026-10-25 — 이 문서는 append하지 않고 매번 "현재 기준"으로 덮어써서 갱신한다. 히스토리는 DEVLOG.md에 남긴다.

## ✅ 완료

- 단계형 사건 워크플로, 14섹션 입찰 보고서, 임장·임차인·수익률 분석
- PDF 업로드로 물건 자동 등록(사건번호·주소·감정가·최저가·입찰일 등 추출), 원문/PDF 탭
- 주변 시세 분석(국토부 실거래·네이버 지도·Gemini 해석), 3단계 리모델링 가이드
- 공부하기(`/study`): 강의 요약본 + 원본 DOCX 다운로드
- 로컬 우선 저장(localStorage + IndexedDB), 스냅샷 복원, 선택적 Supabase 병합
- **검색·수집**: 태인경매(`/taein`)·대법원(`/court`) 검색 결과 입찰일 가까운 순 정렬, 용도·유찰·예산·특이사항 기준 **판정(레드/옐로/그린)**, 선택 물건 등록
- **태인 상세 자동 수집**: 사진·그래프·표와 문서 5종(감정평가서·등기부등본·건축물대장·매각물건명세서·현황조사서), 누락 시 상세에서 「다시 수집」, 문서는 항상 같은 창에서 열기
- **층별 평면도**: 감정평가서에서 건물 개황도를 자동 추출해 상세에 표시
- **스크리닝**: 문서 글자로 위험 신호(인수 보증금·유치권 등) 탐지, 직접 확인 체크리스트, **최대 입찰가 역산**, 기준값 설정(`/screening`)
- **입찰 가이드 프로세스**: 발굴 → 권리 → 시세·수익 → 임장 → 자금 → 입찰가 6단계와 Go/보류/중단 판정 (프로세스 메뉴·물건 상세)
- **물건 목록**: 전체 갱신(낙찰·유찰·최저가·입찰일), 삭제 / 완전 삭제(수집 원본 포함)
- **화면 설정(`/settings`)**: 사이드 메뉴 숨기기, 글자 크기, 밝기·뉴/올드 UI, 상단 소식(최근 개발사항·관심물건 변동 2줄), 상세 블록 순서, 새 기능 NEW 표시
- 상단 메뉴를 왼쪽 사이드바로 이동

## 🐞 알려진 이슈

- 스크리닝 키워드 검사는 오탐·누락이 있을 수 있어 보조 수단이다(스캔본 PDF는 글자를 읽지 못함)
- 태인경매는 동시 로그인을 한 곳으로 제한해, 수집기가 로그인하면 다른 기기의 태인 세션이 끊길 수 있다
- 입찰가 역산의 취득세율·대출 조건은 설정값(확인 필요) — 보유 주택 수·규제에 따라 직접 조정해야 한다
- 층별 평면도는 제목이 다른 표기이거나 스캔본이면 찾지 못할 수 있고, 호별 방 구조·방 개수는 직접 입력한다
