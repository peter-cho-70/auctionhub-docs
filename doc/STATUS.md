## ✅ 완료

- **검색·수집**: 태인경매·대법원 검색 결과를 입찰일 가까운 순으로 보고, 용도·유찰·예산·특이사항 기준 **판정(레드/옐로/그린)**, 선택 물건 등록
- **태인 상세 자동 수집**: 사진·그래프·표와 문서(감정평가서·등기부등본·건축물대장·매각물건명세서·현황조사서), 누락 시 「다시 수집」, 문서는 항상 같은 창에서 열기
- **스크리닝**: 문서 글자로 위험 신호 탐지, 직접 확인 체크리스트, 최대 입찰가 역산, 기준값 설정(`/screening`)
- 물건 목록: 전체 갱신, 삭제/완전 삭제, 층별 평면도 자동 추출, 화면 설정(`/settings`)

### 2026-10-25 추가 (자세한 내용은 spec/ 설계 문서)
- **데이터 보호**: 이 컴퓨터 디스크(`private/backups/`)에 자동 백업(앱 열 때·변경 15초 뒤·삭제 직전), 물건 최다 시점 보존, 저장 읽기 실패 시 원본 보존·저장 중지, 목록이 비면 복구 배너, 「새로 시작」 직전 백업 — [데이터 보호 설계](spec/DATA-PROTECTION-DESIGN.md)
- **저장 용량**: 리모델링 기본값을 저장하지 않는 방식으로 물건 38건 약 63% 감소, 사용률 막대·80% 경고 — [저장 용량 설계](spec/STORAGE-SLIM-DESIGN.md)
- **임장 후보 점수**: 내 패턴 분석에 검색방향(12개 항목·중요도·기준값)을 기록, 저장된 물건을 자동 점수화(`/scouting`), 수동·자동 후보 등록, 임장 전 입력·임장 후 기록 — [임장 후보 점수 설계](spec/SCOUTING-SCORE-DESIGN.md)
- **지도·임장 동선**: 후보를 지도에 번호로 표시, 최단 순서 정렬, 출발지·시간 추정, 마커를 끌어 위치 보정 — [지도·동선 설계](spec/SCOUTING-MAP-ROUTE-DESIGN.md)
- **자동 임장물건 찾기**(`/auto-scout`): 한 건씩 천천히(건 사이 25초), 1회 5건·하루 15건, 검색 재사용 6시간, 실패 시 중단 — [자동 찾기 설계](spec/AUTO-SCOUT-DESIGN.md)
- **태인 연동 확장**: 권리분석·수익률계산기·전입세대열람 화면을 PDF로 저장, 권리분석 구조화 저장, 태인 방식 수익률 계산기(등기·명도비용 공식 포함), 「토지 비용 80% 이상」 표시 — [태인 연동 설계](spec/TAEIN-INTEGRATION-DESIGN.md)
- **임차관계 표시**: 호실 기준 정리, 전입 오래된 5명·고액 보증금·미배당 고액·LH·소액·주인세대 표시, 전세/월세 구분, 최근 2년 시세 비교, 월세 미납 삭감 추정 — [임차관계 표시 설계](spec/TENANT-VIEW-DESIGN.md)
- **화면**: 기본정보 점수 항목 ★와 단계 색(녹색 만점·파랑 중상·검정 보통·빨강 평균 이하), 노란 메모지, 메뉴 옆 개수(물건 목록·태인 신규), 모든 숫자 천 단위 쉼표, 버전에 업데이트 시각 — [화면 가이드](guide/UI-GUIDE.md)

## 🐞 알려진 이슈

- **목록 소실의 정확한 원인은 미확인**: 2026-10-25 목록이 비워졌으나 원인을 밝히지 못했다(증거 정리는 [점검 리포트](report/2026-10-25-data-loss-investigation.md)). 대신 디스크 백업·저장 보호 장치로 복구 가능하게 했다.
- **자동 임장물건 찾기 실전 미검증**: 속도·한도·재시도·중지는 가짜 환경으로 검증했고, 실제 태인 사이트로 등록→임장 후보 승격까지는 아직 해 보지 않았다(처음에는 1회 1건으로 시험 권장).
- **지도 위치는 동 단위 추정**: 지번 좌표 키(주소 검색·지도 서비스)가 없어 자동 위치는 수백 m~1km 오차. 마커를 끌어 보정하거나 키를 설정하면 정확해진다.
- **확인이 필요한 상수**: 국민주택채권 매입률 3.1%·할인율 9%, 인지세 구간(1억~10억만 확인), 소액임차인 보증금 상한 기본 8,500만원, 월세 미납 가정 6개월, 태인 「승강기」 칸 표기 형식.
- **브라우저 저장 한도**: 물건 데이터가 브라우저 저장소(약 5MB) 안에 있어 약 90건이 한계. 체크리스트 중복(약 9%)은 아직 줄이지 못했다.
- **백업 복사본이 한 곳**: 디스크 백업은 외장 SSD(`data`) 하나뿐이다(시간 백업 미설정). USB 연결이 끊기면 백업이 실패한다.
- 스크리닝 키워드 검사는 오탐·누락이 있을 수 있다(스캔본 PDF는 글자를 읽지 못함). 태인 동시 로그인 제한으로 수집기 로그인이 다른 기기 세션을 끊을 수 있다.
- 리모델링 카탈로그 비용줄의 가격은 불러올 때 카탈로그 값으로 다시 채워진다(선택 여부만 유지) — 기존 동작.
