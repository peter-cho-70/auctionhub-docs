# 점검 리포트 — 2026-10-25 개발 검증 결과

## 2. 개발 중 발견해 고친 문제

- 저장 보호 장치가 「저장된 값 없음」을 오류로 오판(저장 차단) → 수정
- 지도 정밀도를 질의 기준으로 표시해 동 단위를 「지번」으로 오표시 → 결과 종류 기준으로 수정
- 최단 순서 근사해가 최적이 아님 → 12곳 이하 정확해로 교체
- 저장에서 뺀 리모델링 단계를 정리 전 기본값으로 채워 값이 달라짐 → 정리 후 기본값으로 수정
- 태인 목록 용도에 「error」 글자 → 아이콘 글자 분리
- 수익률의 채권 할인 손실 1원 차이 → 반올림으로 맞춤

## 3. 검증하지 못한 것

- **자동 임장물건 찾기의 실제 태인 사이트 전체 흐름**(수집→등록→승격). 가짜 환경 검증만 했다.
- **전입세대열람 팝업**의 실제 형식, 새로 받은 문서가 실제 팝업에서 저장되는지(권리분석·수익률계산기 PDF 저장은 팝업 화면 확인까지 했으나 새 수집 경로의 전체 실행은 미실행).
- **지번 단위 위치**(지오코딩 키 없음), 「현재 위치」 버튼과 마커 끌기의 실제 조작.
- 상세 화면의 수익률 계산기·토지 80% 표시의 일부 화면(해당 데이터가 없는 상태라 규칙 테스트로 대체).
- 테스트 브라우저는 창에 포커스가 없어 일부 포커스 이벤트를 직접 일으켜 확인했다.
