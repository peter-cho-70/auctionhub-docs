## 2026-10-29 (밤) — 임장 모바일 연동 방법론 문서

- **추가**: [임장 모바일 연동 방법론](spec/FIELD-MOBILE-SYNC-DESIGN.md) — 폰(Android Chrome)에서 임장 정보를 보고·수정·신규 입력하고 Mac 로컬에 합치는 방법. 원본은 Mac, 폰은 작업 사본, 변경은 변경 묶음으로 돌려 미리 보기·충돌 해결·백업 후 반영. 통로 A(파일) + 통로 B(Tailscale, PWA 설치·자동 동기화) 병행. **코드 구현은 없음(방법론만)**.
- **확인한 현재 제약**: 데이터는 브라우저 IndexedDB라 폰이 서버에 접속해도 비어 있음, 서버 화면은 같은 Wi-Fi 주소로도 열리지만 `backup`·`pinned/upload` API는 Host가 localhost가 아니면 403, 「JSON 전체 보내기」는 삭제된 기능이라 임장 물건만 잘라 낸 팩을 새로 만들어야 함.
- **정리**: 문서 맨 위에 ⭐ 「해야 할 일」 표시, STATUS에 「⭐ 해야 할 일」 섹션(모바일 연동, 세종 아파트 자료, 명세서 PDF 읽기, 왕복 검증, 일괄 재계산, `.playwright-mcp` 무시 여부)을 만들고 다음 우선순위·진행 중 항목도 맞춤.
- **열린 점**: 파일 전송 방법(USB/Taildrop/Syncthing), 현관 비밀번호 기본 포함 여부, 모바일 전용 화면 여부, Tailscale HTTPS 인증서·`tailscale serve` 절차(확인 필요).
