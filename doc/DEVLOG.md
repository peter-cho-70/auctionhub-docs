  - **건폐율·용적률 말풍선**(뜻과 한도 대비 좋음/나쁨), 대항력 임차인에 말소기준일·전입 일수 표시

## 2026-10-25 (오후~밤) — 데이터 소실 대응, 임장 후보·지도 동선, 자동 임장물건 찾기, 태인 연동 확장

- **추가/변경**
  - **데이터 보호**: 이 컴퓨터 디스크(`private/backups/`) 자동 백업, 저장 보호 장치, 복구 배너, 「새로 시작」 직전 백업, 백업·복구 화면을 데이터 화면 맨 위로 — [설계](spec/DATA-PROTECTION-DESIGN.md)
  - **저장 용량**: 리모델링 기본값을 저장하지 않고 불러올 때 다시 채움(물건 38건 약 5.5M자 → 약 2.05M자), 용량 사용률 막대와 80% 경고 — [설계](spec/STORAGE-SLIM-DESIGN.md)
  - **임장 후보**: 내 패턴 분석에 검색방향 기록(12개 항목), 자동 점수화·추천, 수동 후보 등록(상세·목록·일괄), 임장 전 입력·임장 후 기록 — [설계](spec/SCOUTING-SCORE-DESIGN.md)
  - **지도·임장 동선**: OpenStreetMap에 후보를 번호로 표시, 최단 순서(12곳 이하는 정확한 최적해), 출발지·소요 추정, 마커 끌어 위치 보정 — [설계](spec/SCOUTING-MAP-ROUTE-DESIGN.md)
  - **자동 임장물건 찾기**: 검색 결과에서 기준에 맞는 물건을 한 건씩 천천히 등록하고 임장 후보 승격, 설정·미리 보기·실행 기록·자동 반복 — [설계](spec/AUTO-SCOUT-DESIGN.md)
  - **태인 연동**: 권리분석·수익률계산기·전입세대열람 화면 PDF 저장, 권리분석 구조화, 태인 방식 수익률 계산기(등기·명도 비용 공식), 「토지 비용 80% 이상」 표시 — [설계](spec/TAEIN-INTEGRATION-DESIGN.md)
  - **임차관계 표시**: 호실 기준, 표시 규칙 다수, 전세/월세·시세 비교·월세 미납 삭감·주인세대 — [설계](spec/TENANT-VIEW-DESIGN.md)
  - **화면**: 기본정보 점수 항목 ★·단계 색, 노란 메모지, 메뉴 개수, 모든 숫자 천 단위 쉼표, 버전 시각, 사진·도면 좌우 이동, 상세 탭(임장자료·수익률 계산기) — [화면 가이드](guide/UI-GUIDE.md)
- **버그 수정**
  - **저장이 막히던 문제(제가 만든 버그)**: 읽기 실패 보호 장치가 「저장된 값 없음」(처음 여는 브라우저·다른 포트)을 오류로 오판해 저장을 멈춤 → 저장된 값이 없으면 기본값으로 시작하도록 수정, 빈 저장소에서 복구 배너·복구 저장까지 확인
  - **태인 목록 용도에 「error」가 붙던 문제**: 태인 아이콘(감정가 중 토지 비용 80% 이상)의 글꼴 이름이 글자로 딸려 옴 → 글자를 떼고 「토지 80%↑ 체크」(옐로)로 표시
  - **지도 정밀도 오표시**: 지번을 넣은 질의도 동 단위 결과를 돌려주는데 「지번」으로 표시하던 것 → 결과의 종류로 정밀도 판정
  - **최단 순서가 최적이 아니던 문제**: 근사 방식만 쓰면 200회 중 22회가 최적이 아니었음(최대 13% 길게) → 12곳 이하는 정확한 최적해로 교체(200회 모두 일치)
  - **수정 후 값이 달라지던 문제**: 저장에서 뺀 리모델링 단계를 정리 전 기본값으로 채워 월세 상승분이 달라짐 → 정리까지 거친 기본값으로 채워 36/36건 동일
- **이슈/막힌 점**
  - **목록 소실 원인 미상**: 활동 기록으로 오늘 14:49~15:19 사이 목록이 비워졌음을 확인했으나 원인은 밝히지 못함. 「새로 시작」은 아니었음(새로 시작 기록 없음, 사진·문서 보관소는 남아 있음). 같은 브라우저에 포트·주소별로 데이터가 따로 쌓여 있는 구조적 약점도 확인 — [점검 리포트](report/2026-10-25-data-loss-investigation.md)
  - **브라우저 저장 한도**: 물건 36건이 한도의 약 97%까지 찬 것을 확인(원인 후보) → 저장 용량 줄이기로 대응, 근본 해결(IndexedDB 이전)은 다음 단계
  - **자동 임장물건 찾기 실전 미검증**, **지도 위치 동 단위 추정**, 일부 상수 확인 필요 — STATUS의 알려진 이슈 참고
