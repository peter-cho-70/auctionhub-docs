# 임차관계 표시 설계

> 기준일: 2026-10-25 · 구현: `src/lib/domain/tenant-flags.ts`, `tenant-market.ts`, `owner-household.ts`, `src/components/case-taein-overview.tsx`(임차관계 표)

## 1. 구성

물건 상세 「임차관계」 표를 **호실 기준**으로 다시 짰다. 같은 호실은 한 칸으로 묶고(호실 순서), 같은 호실 안에서는 전입이 오래된 순, 호실을 모르는 임차인은 맨 아래 「호실 미상」에 모은다. 표 위에 범례, 아래에 총보증금·총월세·근거 줄이 있다.

## 2. 표시 규칙

| 표시 | 조건 | 모양 |
|---|---|---|
| 전입 N위 | 전입일이 가장 오래된 5명(날짜가 있는 임차인만) | 하늘색 배지 |
| 고액 보증금 | 보증금 ≥ 설정값(기본 1억원) | 보증금 굵은 빨간색 |
| 미배당 고액 | 미배당액 ≥ 설정값(기본 3,000만원) | 미배당 굵은 빨간색 |
| 미배당>배당 | 미배당액이 배당액보다 큼 | 주황 배지 |
| LH | 이름에 「한국토지주택공사」·「엘에이치」·「LH」 | 보라 배지·이름 |
| 소액 | ① 비고·메모에 「소액」 ② 예상배당표의 소액 권리자 ③ 보증금 ≤ 설정 상한(기본 8,500만원, 추정) | 녹색 배지·행 배경(근거는 마우스를 올리면 표시) |
| 전세 / 월세 | 월세가 있으면 월세, 보증금만 있으면 전세 | 전세 남보라 / **월세 빨간 굵은 글씨** |
| 주인세대 | 아래 4절 | 자홍색 배지 |

설정값은 **스크리닝 기준** 화면에서 바꾼다(소액 상한은 지역·소액임차기준일에 따라 달라 확인 필요, 0이면 금액으로는 판정하지 않음).

## 3. 시세 비교와 월세 미납 삭감

- **시세 비교**: 임차인의 현재 보증금·월세를 **최근 24개월 평균 전월세**와 비교한다. 평균은 물건의 「주변 시세」 탭에 가져온 전월세 거래를 우선 쓰고, 없으면 태인의 국토부 실거래가 표를 읽는다. 오차 ±10%(설정) 이내는 회색(비슷), 높으면 빨강, 낮으면 파랑. 전세는 전세금, 월세는 월세와 보증금을 각각 비교한다. 면적·방 구조는 반영하지 않는 전체 평균이다.
- **월세 미납 삭감**: 월세 임차인은 경매가 진행되는 동안 월세를 내지 않는 경우가 많아 예상 보증금이 줄 수 있다. 「월세 N개월 미납 시 보증금 약 X」(= 보증금 − 월세 × N, 0 미만은 0)를 참고로 표시한다(기본 6개월, 설정). 예상배당표는 접힌 상태로 시작하고 같은 취지의 안내를 붙였다.

## 4. 주인세대(소유자·채무자 본인 세대) 찾기

세 가지 근거를 모두 본다.

1. 임차인표에서 이름이 소유자·채무자와 같거나 비고에 「소유자·주인·채무자 점유」 표기가 있는 임차인
2. 전입세대 열람내역에 소유자·채무자와 같은 이름
3. 현황조사서·매각물건명세서 문구에 「소유자(채무자) 점유·거주」가 있는 줄

표시: 임차관계 표의 배지와 하단 근거 줄, 기본정보 「건물」 줄의 「주인세대 N곳」, 임장자료 호실 특이사항·건물 전체 특이사항. 개인정보 가림(O) 표기 그대로 이름을 비교해 동명이인·표기 차이로 틀릴 수 있고, 법인 소유는 이름으로 못 찾아 문구로만 판단한다(추정).

## 5. 임장자료의 상태 표기

호실 상태 「임차 중」을 **「월세」**로 바꾸고 빨간 굵은 글씨로 표시한다(전세·공실 후보·임차인 미확인은 그대로). 화면·HTML·마크다운 내보내기에 모두 적용.

## 6. 검증

가짜 임차인 7명으로 전입 순위·고액·LH·미배당·소액·호실 묶기·정렬을 확인했고, 시세 비교(전세 +36% 높음 등)와 월세 미납 삭감 계산, 주인세대 세 가지 근거 탐지(없는 경우 0건)를 확인했다.
