# 태인 연동 확장 설계 — 권리분석 · 수익률계산기 · 전입세대열람 · 토지 비중 표시

> 기준일: 2026-10-25 · 구현: `scripts/collector/scrape-taein-detail.mjs`, `src/lib/collector/taein-rights.ts`, `taein-register.ts`, `src/lib/domain/taein-yield.ts`, `case-taein-yield.ts`, `src/components/case-yield-calculator.tsx`

## 1. 수집하는 문서 (태인 문서 버튼, 같은 창에서 열림)

| 문서 | 방식 |
|---|---|
| 감정평가서·등기부등본·건축물대장·매각물건명세서 | 팝업 안 PDF를 직접 받음(기존) |
| 현황조사서 | 화면(HTML)을 PDF로 인쇄(기존) |
| **전입세대열람** | 같은 방식으로 시도 — 팝업이 PDF가 아니면 화면을 인쇄해 저장(실제 팝업 형식은 미확인) |
| **태인권리분석** | 버튼을 눌러 뜨는 팝업을 **화면 그대로 PDF로 저장** + 글자를 구조화해 저장 |
| **수익률계산기** | 팝업 화면을 PDF로 저장 |

- 팝업은 폼 제출로 열려 클릭 응답이 늦을 수 있어, 클릭을 기다리지 않고 새 탭이 보일 때까지 확인한 뒤 내용이 그려질 때까지(최대 약 12초) 기다린다. 실패한 문서만 건너뛰고 나머지는 계속한다.
- 기존 물건은 「다시 수집」으로 받아야 새 문서가 생긴다.

## 2. 권리분석 구조화 (`rightsAnalysis`)

태인권리분석 화면의 글자를 분석해 저장한다: 말소기준권리, 배당할 금액, 예상배당표(권리·권리자·날짜·채권액·배당금·미수금·인수·비고), 권리자별 상세 설명(소액임차인 해당 여부·배당 순서·대항력·인수 여부), **인수금액**, **경매취하 가능성**, 매각불허가(무잉여) 설명, **인도명령 대상**, **대위변제 가능성**(후순위 임차인이 선순위 권리를 대신 갚아 대항력을 얻을 수 있는지), 인근 낙찰통계, **적정입찰가**(감정가 × 평균낙찰가율, 인수금액 미반영), 비용·수익성.

- 금액 표기(「8억4,000만원」「9,500만원」)는 원 단위 숫자로 바꾼다.
- 화면 PDF가 문서로 저장되면 전문 글자 사본은 저장하지 않는다(용량 절약). 못 받았으면 글자 사본을 남긴다.
- **미반영**: 이 분석을 위험 신호(대위변제·무잉여)·점수에 반영하는 것은 아직 하지 않았다.

## 3. 태인 방식 수익률 계산 (상세 「수익률 계산기」 탭, 임장 후보 「임대 수익」)

태인 「임대수익률 계산기」의 화면 값과 스크립트를 읽어 식을 옮겼다(처음 값은 이 물건의 최저가·감정가·임차인으로 채우고 모두 수정 가능, 입력은 저장하지 않음).

| 항목 | 식 |
|---|---|
| 낙찰가 기본값 / 대출 기본값 | 최저가 / 낙찰가의 50% |
| 입찰보증금 | 최저가의 10% |
| 낙찰 후 필요자금 | 낙찰가 − 입찰보증금 − 대출금 |
| 컨설팅 수수료 | 낙찰가 × 1% |
| **실투자금** | 입찰보증금 + 등기비용 + 명도비용 + 인수금액 + 필요자금 + 컨설팅 + 기타 비용 (대출금은 빠짐) |
| 월 이자 / 연 이자 | 대출금 × 금리 ÷ 1200 / ÷ 100 (내림) |
| 임대조건 환산 | 보증금이 3,000만원을 넘으면 초과분 ÷ 200을 월세에 더하고 보증금은 3,000만원으로 |
| 월 수익 | 월 임대료 + 기타수입 − 월 이자 − 월 고정지출 (연 수익 = ×12) |
| 자기자본 실투자금 | 실투자금 − (환산 후) 임대보증금 |
| **임대수익률** | 연 수익 ÷ 자기자본 실투자금 |
| 시세차익 | 현시세(기본 감정가) − 낙찰가 |

임차인 정보가 없으면 태인처럼 보증금 = 낙찰가의 5%, 월세 = 낙찰가의 0.25%로 추정한다.

## 4. 등기비용·명도비용 공식

**등기비용(주택, 1~2주택·조정대상지역 외 기준)** = 취득세 + 지방교육세 + 농어촌특별세(전용 85㎡ 초과) + 국민주택채권 할인 손실 + 인지세 + 수입증지대 15,000원

- 취득세율: 6억 이하 1% / 6~9억 `(취득가×2/3억 − 3)%`를 소수 둘째 자리에서 **내림** / 9억 초과 3%. 지방교육세 0.1·0.2·0.3%, 농어촌특별세 0.2%
- 채권: 취득가 × 3.1% 매입, 할인 손실 = 매입액 × 9%(반올림)
- 인지세: 1억 초과~10억 이하 15만원(태인 화면으로 확인한 구간), 나머지 구간은 인지세법 기준(확인 필요)
- 취득세 중과 구분(8%·12%)도 선택 가능(태인 산정기준표를 단순화)
- 주택 외: 취득세 4% + 지방교육세 0.4% + 농어촌특별세 0.2%

**명도비용(주거)** = 건물 평수 × 10만원, 최저 120만원 (공장 평당 5만원·최저 700만원, 토지 0원).

## 5. 검증

예시 사건 하나에서 태인 화면의 월 이자·낙찰 후 필요자금·실투자금·연 수익금·자기자본·**임대수익률**·시세차익이 모두 일치했고, 등기비용 합계와 취득세 세부, 명도비용도 일치했다(채권 할인 손실의 1원 차이는 반올림으로 맞춤).

> 태인 계산기의 등기비용은 페이지를 열 때 정해진 값이라 낙찰가를 바꿔도 따라 바뀌지 않는다. 이 앱의 계산기는 낙찰가에 맞춰 다시 계산한다.

## 6. 「토지 비용 80% 이상」 표시

- 태인 검색 결과의 용도 칸에 붙는 「i」 아이콘은 **감정가 중 토지 비용이 80% 이상**인 물건이라는 뜻이다(사용자가 마우스를 올려 확인).
- 아이콘의 글꼴(Material Icons) 이름이 글자로 딸려 와 용도가 「error 다가구」로 저장되던 것을, 글자를 떼고 `landHeavy` 표시로 바꿨다(수집 스크립트와 저장된 검색 결과를 읽을 때 모두 정리).
- 표시: 검색 결과 표의 노란 「토지 80%↑ 체크」, 스크리닝 옐로(「토지 비용 80% 이상 — 나중에 체크」), 등록한 물건의 메모·사건 스크리닝 옐로 신호·목록 줄의 노란 표시. 레드가 아니라서 자동 임장물건 찾기에서도 후보에서 빠지지 않는다.
- 예전에 「error 다가구」로 등록된 물건은 불러올 때 글자를 떼고 같은 표시로 옮긴다.

## 7. 한계

- 채권 매입률·할인율, 인지세 구간, 취득세 중과 구분은 시점·조건에 따라 달라지는 값이다(확인 필요).
- 전입세대열람 팝업의 실제 형식은 아직 수집본으로 확인하지 못했다.
- 모든 계산은 참고용 추정이며 법무사·세무 확인을 대신하지 않는다.
