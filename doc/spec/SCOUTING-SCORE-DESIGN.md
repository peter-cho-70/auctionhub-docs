# 임장 후보 점수 설계 — 내 물건 검색방향

> 기준일: 2026-10-25 · 구현: `src/lib/direction/`(settings·analyze·normalize·scouting), `src/app/scouting/`, `src/components/scout-card.tsx`, `search-direction-settings.tsx`

## 1. 목적

「어떤 물건을 찾는지」를 기록하고, 저장된 물건을 그 기준으로 자동 점수화해 임장할 물건을 고른다. 기준과 중요도는 **내 패턴 분석 > 내 물건 검색방향**에서 바꾼다(이 브라우저에만 저장).

## 2. 평가 항목 (12개)

점수는 0~1로 계산한 뒤 중요도(0~10)로 가중 평균한다. 확인하지 못한 항목은 점수에서 빼고 「확인 필요」로 남긴다.

| 항목 | 기본 중요도 | 입력 | 점수식(기본 기준값) |
|---|---|---|---|
| 입지(인구·교통·시설) | 8 | 직접 1~5점 3개(거주 인구·지하철/버스·주변 시설) | 입력한 값의 평균 → (평균−1)/4 |
| 건물 외관 | 5 | 사진 보고 또는 임장 후 1~5점(임장 후 값이 우선) | (값−1)/4 |
| 준공 시기 | 6 | 건축물대장 사용승인일 → 입력한 준공연도 | 건물 나이 ≤ 5년이면 1, 15년 이상이면 0, 사이는 직선 |
| 임대 호실 수 | 7 | 건축물대장 세대수 → 임차인 수 | (호실−2)/(10−2) |
| 건물면적 | 6 | 저장된 건물면적 → 대장 연면적 | 면적 ÷ 500㎡ (500㎡ 이상 만점) |
| 용적률 | 5 | 저장된 용적률 → 대장 | 용적률 ÷ 250% |
| 주차 대수 | 5 | 대장 주차 합계 → 입력값 | 대수 ÷ 10 |
| 엘리베이터 | 4 | 대장 승강기(숫자 합>0이면 있음, 「없음」·「-」는 없음) → 다가구 분석의 작동 확인 | 있음 1 / 없음 0 |
| 임차인 배당 회수율 | 8 | 임차인표의 배당액 | Σ min(배당액, 보증금) ÷ Σ 보증금 (배당액이 적힌 임차인만) |
| 임차인 안전성 | 9 | 임차인표·월세 상계 확인 | 아래 3절 |
| 임대 수익 | 9 | 태인 방식 수익률(최저가 기준) | 수익률 ÷ 8% |
| 시세 대비 하락 | 8 | 입력·추정한 시세 | (1 − 최저가/시세) ÷ 25% |

## 3. 임차인 안전성

- 임차인 정보가 없으면 확인 필요.
- 낙찰자 인수 보증금이 있으면 낮게: `0.35 × (1 − 인수액/보증금)`.
- 인수액은 없지만 대항력 있는 임차인의 배당이 전액이 아니면 0.5 + 「배당 여부를 매각물건명세서로 확인」.
- 대항력을 모르는 임차인은 1명당 0.1 감점(최대 5명).
- 월세 상계 확인(`confirmed`)을 직접 입력하면 인수액 없음 1.0 / 있음 0.75.
- 월세 상계는 자동으로 단정하지 않는다. 대항력은 있고 배당이 전액이 아니며 보증금이 월세의 10배 이하인 임차인은 「월세 상계 가능성 — 확인 필요」로만 표시한다.

## 4. 총점·추천

- 총점 = Σ(중요도×점수) ÷ Σ(확인된 항목의 중요도) × 100
- 확인 비율 = 확인된 항목 중요도 ÷ 전체 중요도
- **추천** = 총점 ≥ 60 이고 확인 비율 ≥ 50% 이고 스크리닝이 레드가 아니며 종료·낙찰 이후 단계가 아니고 아직 후보가 아닌 물건

## 5. 점수 단계 색 (물건 상세 기본정보의 ★ 항목)

| 색 | 의미 | 점수 |
|---|---|---|
| 녹색 | 만점 | 0.995 이상 |
| 파랑 | 중상 | 0.67 이상 |
| 검정 | 보통 | 0.34 이상 |
| 빨강 | 평균 이하 | 0.34 미만 |

## 6. 화면

- **임장 후보(`/scouting`)** 탭 5개: 추천 / 임장 후보 / 임장 완료 / 전체 점수순 / 지도·동선. 카드에 최저가·입찰일·준공·호실·임차인 요약·항목별 근거·위험 신호·지도 링크.
- **수동 후보 등록**: 물건 상세 머리의 「임장 후보로」, 물건 목록 줄의 버튼, 목록에서 여러 건 선택 후 「선택한 N건 임장 후보로」.
- **임장 전 입력**: 입지 3항목·외관 점수, 월세 상계 확인(아직/없음/있음/불확실).
- **임장 후 기록**: 임장일, 현장 외관, 실제 공실, 주변 임대 시세, 주변 환경, 월세 상계 면담, 메모, 판단(진행/보류/포기).
- 데이터: 물건 필드 `searchDirection`(선택 필드, 없으면 null) — 기존 물건은 변경되지 않고 백업에 포함된다.

## 7. 한계

- 입지·외관은 직접 입력이라 임장 전 점수에는 빠진다(자동 점수화는 나중에).
- 기준값·중요도는 초기 추정이므로 실제 물건으로 보며 조정해야 한다.
- 수익률은 임차인표가 없으면 태인처럼 보증금 5%·월세 0.25%로 추정한다(태인 연동 설계 참고).
