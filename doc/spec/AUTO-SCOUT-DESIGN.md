# 자동 임장물건 찾기 설계

> 기준일: 2026-10-25 · 구현: `src/lib/auto-scout/`(settings·select·run·controller), `src/lib/collector/taein-register.ts`, `src/app/auto-scout/`, `src/components/auto-scout-scheduler.tsx`

## 1. 목적

수동으로 하던 **「태인 검색 → 정렬·선택 → 물건 목록 등록 → 임장 후보 등록」**을 자동으로 이어 준다. 시스템과 태인경매 사이트에 부담이 없는 속도로 천천히 진행하고, 새 물건만 추가한다(기존 물건을 지우거나 덮어쓰지 않음).

## 2. 흐름

```
검색 결과 확인(6시간 안이면 재사용, 오래됐으면 한 번 검색)
  → 후보 고르기(이미 받은 목록으로만 계산, 요청 없음)
  → 시작 전 백업(디스크 포함)
  → 한 건씩: 상세 수집 → 물건 등록(사진·문서·권리분석·스크리닝) → 임장 후보 승격 판단 → 쉬는 시간
```

## 3. 고르는 기준과 순서

**건너뜀**: 이미 등록된 사건번호 / 상태가 취하·취소·기각·정지·변경·연기·낙찰·매각 / 입찰일을 읽을 수 없음 / 입찰까지 남은 일수가 범위(기본 5~30일) 밖 / 스크리닝 레드(용도 불일치·유찰 5회 이상·예산 초과·위험 키워드).

**정렬**: 판정 그린 → 옐로, 같은 판정 안에서는 입찰일이 가까운 순. 이 순서로 **1회 한도와 오늘 남은 한도 중 작은 만큼** 위에서부터 등록하고, 넘는 물건은 다음 실행으로 넘어간다.

**임장 후보 승격**: 등록 후 임장 후보 점수가 기준(추천 60점·확인 비율 50%)을 통과하고 스크리닝이 레드가 아니면 후보로, 아니면 물건 목록에만 두고 이유를 기록한다.

## 4. 부담을 줄이는 규칙

| 규칙 | 기본값 | 하한/상한 |
|---|---|---|
| 한 번에 처리하는 건수 | 1건(동시 요청 없음) | 고정 |
| 건 사이 쉬는 시간 | 25초(±30% 무작위) | 10~600초 |
| 1회 최대 등록 | 5건 | 1~20 |
| 하루 최대 수집 시도(실패 포함, 자정 초기화) | 15건 | 1~60 |
| 검색 결과 재사용 | 6시간 | 1~168시간 |
| 서버가 바쁠 때 | 45초 기다려 최대 3번 재시도 | 고정 |
| 연속 실패 | 3건이면 즉시 중지 | 고정 |
| 다른 가져오기와의 충돌 | 실행 중에는 다른 태인 가져오기를 막음 | 고정 |
| 대법원 상세 | 기본 끔(다른 사이트를 한 번 더 조회) | 선택 |

검색은 가장 무거운 요청이라 6시간 안에는 새로 하지 않는다. 실패해도 쉬는 시간을 두므로 몰아치지 않는다.

## 5. 화면(`/auto-scout`, 사이드 메뉴)

- 「지금 실행」 / 「미리 보기(요청 없음)」 / 「중지」, 진행률·단계 표시, 오늘 사용량·마지막 실행·마지막 검색 시각, 예상 소요 시간
- 미리 보기: 등록 예정 목록(순서 그대로)과 건너뛴 물건·이유, 한도 때문에 미룬 건수
- 속도·한도 설정, 「앱이 열려 있는 동안 자동 반복」(기본 끔, 간격·활동 시간대 설정), 실행 기록(최근 200건)
- 「무엇을 찾나」에 검색 조건·등록 대상·**등록 순서**·승격 기준·안전 장치 설명

## 6. 검증

- 실행기는 바깥 동작(검색·수집·등록·시간)을 주입받는 구조라 가짜 환경에서 시나리오를 검증했다: 정상 3건(쉬는 시간 25초 ×2), 검색 결과 10시간 지남→새로 검색 1회, 미리 보기(요청 0), 하루 14/15 사용→1건만, 한도 소진→즉시 종료, 날짜가 바뀌면 한도 초기화, 서버 바쁨 2번 후 성공(45초 ×2), 연속 3건 실패→나머지 요청 없이 중단, 로그인 안 된 검색 결과→등록 안 함, 첫 건 뒤 중지, 1회 한도 2건.
- 실제 저장된 검색 결과 30건으로 미리 보기를 실행: 5건 등록 예정·7건 건너뜀·18건은 한도 때문에 미룸으로 정상 계산.

## 7. 한계·남은 일

- **실제 태인 사이트로 등록→승격까지 끝까지 돌려 보지는 못했다.** 처음에는 「1회 최대 등록」을 1건으로 낮춰 시험할 것.
- 입지·외관 점수는 임장 전에는 비어 있어 승격 점수에서 빠진다(임장 후 재평가 필요).
- 자동 반복은 앱 화면이 열려 있는 동안만 동작한다.
