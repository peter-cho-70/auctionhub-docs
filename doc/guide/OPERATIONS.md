# 운영 가이드 — 백업·복구·설정·안전 수칙

> 기준일: 2026-10-25

## 1. 데이터가 있는 곳

| 위치 | 내용 | 비고 |
|---|---|---|
| 브라우저 localStorage `auctionflow:v1` | 물건 데이터 본체(약 5MB 한도) | **주소·포트·브라우저마다 따로**. 사이트 데이터 삭제 시 사라짐 |
| 브라우저 IndexedDB | 사진·PDF·평면도 파일, 브라우저 백업 | 사이트 데이터 삭제 시 함께 사라짐 |
| **`private/backups/`(이 컴퓨터)** | 물건 데이터의 **디스크 백업**(gzip) | 브라우저와 무관하게 남음 |
| `private/collector/` | 태인 수집 원본(사진·문서·검색 결과) | 물건 「완전 삭제」 시 함께 삭제 |

항상 **같은 주소·같은 브라우저**로 연다(예: `localhost:3000`). 목록이 비어 보이면 먼저 주소를 확인한다.

## 2. 복구 절차

1. **목록이 비었을 때**: 앱을 열면 상단에 「디스크 백업에 현재 목록에 없는 물건 N건이 있습니다」 배너가 뜬다 → 「어떤 물건인지 보기」로 확인 → 「없는 물건 N건 복구(병합)」.
2. **원하는 시점으로 복구**: 데이터 화면 맨 위 「백업·복구」 > 「디스크 백업」 목록에서 시점을 골라 「없는 물건만 복구(병합)」 또는 「이 백업으로 교체」. 작업 직전 상태는 자동으로 다시 백업된다.
3. **파일로 직접**: `private/backups/*.json.gz`를 `gunzip -c 파일.json.gz > backup.json`으로 풀고, 「백업 파일에서 복원」으로 불러온다.
4. 사진·PDF 파일은 백업에 없으므로 물건 상세의 「다시 수집」으로 받는다.

> 「모두 삭제하고 새로 시작」 버튼은 누르지 않는다. 눌러도 직전 상태가 디스크에 남지만(저장 실패 시에는 지우지 않음), 브라우저 안의 데이터와 수집 원본은 지워진다.

## 3. 설정 위치

| 무엇을 | 어디서 |
|---|---|
| 판정 기준(유찰·예산·키워드), 세율·대출, 고액 보증금·미배당·소액 상한, 월세 미납 가정, 시세 비교 오차 | 스크리닝 기준(`/screening`) |
| 내 물건 검색방향(항목·중요도·기준값), 임장 후보 추천 점수 | 내 패턴 분석(`/patterns`) |
| 자동 임장물건 찾기의 속도·한도·반복 | 자동 임장물건 찾기(`/auto-scout`) |
| 태인 검색 조건(지역·용도·기간) | 태인경매 검색(`/taein`) |
| 메뉴 숨기기·글자 크기·밝기 | 설정(`/settings`) |
| 디스크 백업 확인·복구, 저장 용량 | 데이터(`/data`) 맨 위 |

## 4. 자동 임장물건 찾기 안전 수칙

- 처음에는 **1회 최대 등록을 1건**으로 낮춰 실제 흐름을 확인한다.
- 건 사이 쉬는 시간은 10초 미만으로 줄 수 없다. 하루 한도는 실패한 시도도 센다.
- 실행 중에는 다른 태인 가져오기가 막힌다. 새로고침하면 중지된다.
- 태인은 동시 로그인을 한 곳으로 제한하므로, 수집기가 로그인하면 다른 기기의 태인 세션이 끊길 수 있다.

## 5. 자주 보는 문제

| 증상 | 원인·조치 |
|---|---|
| 상단 빨간 「저장을 멈췄습니다」 | 저장된 데이터를 읽다 오류가 난 경우. 원본은 디스크에 보존돼 있다. 새로고침해도 같으면 디스크 백업에서 복구 |
| 상단 노란/빨간 「브라우저 저장 용량 N%」 | 80%↑ 경고. 디스크 백업에는 전체가 있다. 데이터 화면에서 사용률 확인 |
| 용도 옆 노란 「토지 80%↑ 체크」 | 태인이 「감정가 중 토지 비용 80% 이상」으로 표시한 물건. 상세에서 토지·건물 감정가 확인 |
| 지도 위치가 동네 중심에 찍힘 | 자동 위치는 동 단위 추정. 마커를 끌어 정확한 위치로 옮기거나 「지도에서 지정」 |
| 디스크 백업 오류 표시 | 개발 서버가 꺼졌거나 외장 드라이브 연결이 끊김. 연결 확인 후 「지금 디스크 백업」 |
| 새 문서(권리분석·수익률계산기·전입세대열람)가 없음 | 기존 물건은 「다시 수집」으로 받아야 생김 |

## 6. 외장 드라이브 주의

프로젝트와 `private/`이 외장 SSD(`data`)에 있다. 연결이 끊기면 개발 서버와 디스크 백업이 함께 멈춘다. 복사본이 한 곳이므로 내부 디스크에 한 부 더 두는 것을 권장(다음 작업 계획).
