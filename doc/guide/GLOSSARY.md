# 용어집

> 법률·세금 용어는 이해를 돕기 위한 간단한 설명이며 법적 조언이 아닙니다. 실제 입찰 전에는 법원 서류와 전문가 확인이 필요합니다.

| 용어 | 뜻 |
|---|---|
| 임장 | 물건 현장을 직접 가서 확인하는 일 |
| 임장 후보 | 임장할 물건으로 올려 둔 물건(수동·자동 등록) |
| 감정가 / 최저가 / 최저가율 | 법원이 정한 감정 가격 / 이번 회차 최저 매각 가격 / 최저가 ÷ 감정가 |
| 유찰 | 입찰자가 없어 매각되지 않고 다음 회차로 넘어가는 것(최저가가 내려감) |
| 말소기준권리 | 낙찰되면 그 뒤의 권리가 대부분 사라지는 기준이 되는 권리 |
| 대항력 | 임차인이 낙찰자에게 보증금을 돌려받을 때까지 집을 비우지 않고 버틸 수 있는 힘 |
| 인수금액 | 낙찰자가 떠안아야 하는 보증금·체납관리비 등 |
| 소액임차인 | 보증금이 일정 금액 이하여서 다른 채권보다 먼저 일정액을 받을 수 있는 임차인(범위는 지역·시점에 따라 다름) |
| 미배당 | 배당 절차에서 보증금을 다 받지 못하고 남은 금액 |
| 무잉여 | 매각대금으로 경매를 신청한 채권자가 아무것도 못 받는 상황(경매가 취소·불허가될 수 있음) |
| 대위변제 | 후순위 임차인이 선순위 권리를 대신 갚아 대항력을 얻는 것 |
| 법정기일 | 세금이 배당 순위를 정할 때 기준이 되는 날짜 |
| 주인세대 | 소유자·채무자 본인이 사는 세대 |
| LH | 한국토지주택공사(매입임대 등으로 임차인이 되는 경우가 있음) |
| 스크리닝 | 서류·목록 정보로 위험 신호를 걸러내는 1차 점검 |
| 판정 레드/옐로/그린 | 위험 신호가 있음 / 확인이 필요함 / 신호 없음(필수 서류가 모두 있을 때만) |
| 토지 80%↑ | 태인이 「감정가 중 토지 비용이 80% 이상」으로 표시한 물건 |
| 확인 비율(커버리지) | 점수를 계산할 수 있었던 항목의 중요도 합 ÷ 전체 중요도 합 |
| 추천 | 임장 후보 점수 기준을 통과하고 레드가 아닌 물건 |
| 디스크 백업 | 브라우저 밖(이 컴퓨터 파일)에 저장하는 물건 데이터 백업 |
| 최다 시점 백업(peak) | 물건 수가 가장 많았던 시점의 백업. 정리에서 제외 |
| 병합 복구 / 교체 복구 | 없는 물건만 추가 / 현재 데이터를 백업 내용으로 통째로 바꿈 |
| 위치 정밀도 | 지번(정확) / 동 단위 추정 / 구 단위 추정 / 직접 지정 |
| 월세 환산 | 보증금이 3,000만원을 넘으면 초과분 ÷ 200을 월세에 더하고 보증금은 3,000만원으로 계산하는 태인 계산기 규칙 |
| 실투자금 | 대출금을 뺀 실제로 들어가는 자금 |
| 자기자본 실투자금 | 실투자금 − 임대보증금 |
| 임대수익률 | 연 수익금(월세−이자 합산) ÷ 자기자본 실투자금 |
| 최단 순서 | 모든 임장 후보를 가장 짧은 이동 거리로 도는 방문 순서 |
