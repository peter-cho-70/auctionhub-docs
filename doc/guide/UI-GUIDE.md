## 사이드 메뉴

- **물건 목록**: 저장된 물건 수가 옆에 표시된다.
- **태인경매 검색**: 마지막 검색 결과 중 아직 등록하지 않은 **신규 N** 배지(파란색). 검색 화면 결과 줄에도 신규·등록됨 건수.
- **임장 후보**, **자동 임장물건 찾기**: 새 메뉴.
- 「관리」 그룹(데이터·계정·설정)은 맨 아래.

## 물건 상세

| 영역 | 내용 |
|---|---|
| 제목 줄 | 제목(예: 「○○동 - 다가구」), 가운데 큰 사건번호, 오른쪽 수집·PDF 버튼 |
| **노란 메모지** | 태인 문서 바로 위. 기본 1줄, 길어지면 최대 2줄(그 이상은 안에서 스크롤). 0.6초 뒤 저장 |
| 기본정보 ★ 항목 | 건물면적·준공·가구·주차·용적률·엘리베이터에 ★와 굵은 글씨. 색은 점수 단계(녹색 만점·파랑 중상·검정 보통·빨강 평균 이하). 아래에 범례, 마우스를 올리면 점수 근거 |
| 단계 탭 | 「② 시세·임장」에 **임장자료**, 「③ 자금·입찰가」에 **수익률 계산기**. 「① 자료·권리」의 같은 탭이 체크박스 줄과 버튼 줄로 두 번 나오던 것을 한 줄로 정리 |
| 태인 문서 | 감정평가서·등기부·건축물대장·매각물건명세서·현황조사서·전입세대열람·태인권리분석·수익률계산기 (같은 창에서 열림) |
| 임차관계 | 호실 기준·표시 규칙·시세 비교·주인세대 — 임차관계 표시 설계 참고 |
| 사진·도면 | 확대 보기에서 ←/→ 키 또는 좌우 버튼으로 같은 묶음(물건사진/도면/그래프) 안에서 이동, 하단에 (3/27) 표시 |
| 임장 후보 버튼 | 머리의 「임장 후보로」(토글) |

## 물건 목록

- 줄마다 「임장 후보로/해제」 버튼과 「임장 후보/임장 완료」 배지, 준공 20년 이상은 주황 「노후 N년」, 태인의 토지 80%↑ 표시는 노란 배지.
- 여러 건을 체크하고 「선택한 N건 임장 후보로」.

## 임장 후보 · 지도

- `/scouting` 탭: 추천 / 임장 후보 / 임장 완료 / 전체 점수순 / **지도·동선**. 카드에서 임장 전 입력·임장 후 기록.
- 지도·동선: 번호 마커, 점선 동선, 최단 순서, 출발지, 소요 추정 — 지도·동선 설계 참고.

## 데이터 화면

- 맨 위 **백업·복구**(디스크 백업 목록·복구), 그 아래 **저장 용량 막대**, 내 데이터는 어디에 있나, 새로 시작 순.
